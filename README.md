# Chat Prefix — Fabric / Minecraft Java 26.2

Мод добавляет `[#D31027-#6A0572] ` в начало обычных исходящих сообщений в чате. Нажми **F8**, чтобы включить или выключить добавление префикса. По умолчанию оно включено. Для работы переключателя требуется Fabric API для Minecraft 26.2.

Пример:
- Ввод: `Всем привет!`
- Отправляется: `[#D31027-#6A0572] Всем привет!`

Исключения для чатов сервера:
- `!текст` — глобальный чат: `!` сохраняется в начале, а цветовой префикс добавляется сразу после него.
- `@текст` и `"текст` — клановый чат: не меняются.
- `$текст` и `;текст` — торговый чат: не меняются.
- `#hand` и `#рука` — тег предмета в руке: не меняются.
- `/команда` — команда: не меняется.

Повторное добавление префикса предотвращается. При выключенном режиме все сообщения отправляются без изменений.

## Сборка JAR в Windows

1. Установи JDK 25 и Gradle (версия 9.5.1 или совместимая с Fabric Loom 1.18).
2. Открой PowerShell в папке проекта.
3. Выполни `gradle build`.
4. Готовый мод появится в `build/libs/chat-prefix-1.0.0.jar`.

## Установка

1. Установи Fabric Loader и Fabric API для Minecraft 26.2.
2. Перемести `chat-prefix-1.0.0.jar` в папку `.minecraft/mods`.
3. Запусти профиль Fabric.

## Важно

Это исходный проект, а не уже собранный JAR. Сборка требует скачивания Minecraft/Fabric зависимостей из официальных репозиториев. Если сборка завершится ошибкой из-за изменения метода `ChatScreen.handleChatInput` в конкретной сборке 26.2, потребуется обновить точку внедрения mixin под эту сборку.


Исправление совместимости: используется KeyMappingHelper для новых версий Fabric API. Уведомление при нажатии F8 отключено, чтобы избежать вызова удалённого метода; переключение префикса остаётся.
